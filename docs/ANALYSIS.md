# 산사(sansatemple.com) 분석

2026-11-01 에 공개 페이지와 내려받은 스크립트를 보고 정리했습니다. 이 레포를 만들 때 무엇을 따라 하고 무엇을 덜어 냈는지 기록합니다.

## 화면에서 보이는 것

- 첫 화면 문구: "산사, 잠깐 쉬어가요", 설명 "말없이 같이 앉아 있는 온라인 절"
- 3D 법당(청연당) 앞마당에서 동자승 캐릭터로 시작. 머리 위에 랜덤 이름표("고요한 바람")
- 안내: "바닥 클릭 · 드래그로 둘러보기 · 휠로 확대/축소"
- 아래 버튼 셋: 합장(3번 키), 절하기(1번 키, 진행 막대), 염주. 춤추기도 숨어 있음
- 위 왼쪽: 나가기, 방 이름과 번호(예: 청연당 69). 누르면 방 목록(서버 1~25)
- 위 오른쪽: 공양미(후원 계좌·카카오페이), 같이 있는 사람 수, 소리, 설정
- "염불 듣기", "함께 듣기": 같은 음원을 같은 시점에 듣는 기능
- 법당 안에는 늘 앉아 있는 스님 넷(고요한 산새, 느긋한 솔잎, 따스한 물결, 은은한 바람)
- 한국 시각 6시~18시는 낮, 나머지는 밤
- 정원·법당·잔치마당 세 구역을 문으로 오감

## 기술 구성 (스크립트에서 확인)

| 부분 | 산사 | 이 레포 |
|---|---|---|
| 화면 | Vite 빌드 + Three.js, glb 모델(불상·소나무·동자승), 재질 텍스처(나무·돌·기와·천) | Three.js 를 빌드 없이 import map 으로, 기본 도형으로만 지음 |
| 실시간 | Cloudflare Workers `wss://…/presence` (방마다 연결), `/api/rooms` 로 방 목록 | Node + ws 서버 하나, `/ws`, `/api/rooms` |
| 메시지 | `move`(x, z, yaw, pose), `hello`, `bow`, `bead`, `seat`, `stand`, `sync`, `room-switch`, 서버는 이진 `delta` 로 바뀐 사람만 보냄 | `move`, `act`, 서버는 0.1초마다 바뀐 사람만 JSON 으로 모아 보냄 |
| 자세 | kneel, walk, beads, dance | stand, walk, kneel, sit, beads |
| 방 | 방 하나 100명, 지역(apac)·인스턴스 구분 | 방 하나 50명(설정), 차면 다음 방 |
| 소리 | 공유마당 CC BY 4.0 염불 음원, 경전 mp3 | WebAudio 로 바람·파도·목탁·종을 합성 |
| 후원 | 계좌·카카오페이·Buy me a coffee | 넣지 않음 |

## 따라 한 것과 덜어 낸 것

따라 한 것: 말없이 같이 있기, 클릭 이동, 이름표, 합장·절·염주, 방 나누기, 늘 있는 NPC, 시각 따라 낮밤, 동작은 서버를 거쳐 모두에게 보이기.

덜어 낸 것: 3D 모델과 텍스처(저작권과 용량), 음원, 구역 이동, 함께 듣기, 후원, 이진 프로토콜.
강의에서 하나씩 붙여 보기 좋은 과제로 남겨 둡니다.
